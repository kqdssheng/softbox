### **Windows 类**

1. MobaXterm：远程终端登录（功能齐全：内置多种服务器角色、本地端支持伪 Linux 命令）👍

3. Proxifier：分应用代理 👍
4. [Scoop](https://github.com/ScoopInstaller/Scoop)：Windows 命令行包管理器（妙用无穷，包山包海）👍👍
